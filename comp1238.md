## Week 1 - Historical Introduction to Text and Writing
- Early writing systems included cave paintings, tally marks, and clay tablets like cuneiform.
- Number systems evolved from the Babylonian base-60 to the Roman and Egyptian systems.
- Printing technology (woodblock, movable type, Gutenberg Press) revolutionized culture and access to knowledge.

## Week 2 - Representing Text and Numbers in Computers
- Computers represent data using binary (bits and bytes); numbers can be unsigned or signed.
- Volatile memory (RAM) loses data without power, while non-volatile storage (SSD/HDD) retains it.
- ASCII and Unicode encode characters into numbers, allowing computers to display and process text.

## Week 3 - Structure of Text
- Text structure in programming relies on lines, indentation, paragraphs, and markup languages like Markdown/HTML.
- Special characters and escape sequences prevent misinterpretation in code and markup.
- Unicode allows representation of more characters than ASCII, commonly using UTF-8 encoding on the web.

## Week 4 - Manipulating Text & Text Editors
- Efficient typing and understanding keyboard layouts improve productivity in coding tasks.
- Text editors (VS Code, Vim) and IDEs help manipulate and manage code effectively.
- Advanced search techniques, including regex and multiple cursors, aid in editing large files quickly.

## Week 5 - Command Line Interfaces
- CLI allows efficient file navigation and manipulation with commands like `ls`, `cd`, `cat`, and `grep`.
- Remote access and file transfer are possible using SSH, SCP, and SFTP.
- CLI tools (htop, tmux, WSL) improve productivity, automation, and system monitoring.
